# Balatro Jokers Reference

A clean, structured list of Jokers formatted as a Markdown table for easy reading and programming use.

The Balatro Wiki sorts Jokers into seven types, depending on their function. The Joker type is denoted using the following symbols:

| Symbol | Joker Type |
| :--- | :--- |
| `+c` | Chips Jokers |
| `+m` | Additive Mult Jokers |
| `Xm` | Multiplicative Mult Jokers |
| `++` | Chips & Additive Mult Jokers |
| `!!` | Effect Jokers |
| `...` | Retrigger Jokers |
| `+$` | Economy Jokers |
